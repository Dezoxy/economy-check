# Template: Event-driven notes

Trigger-based posts between weeklies. Output: Hungarian. Faster register: drop the ceremonial
opening when urgency is real; time-stamped verbs ("ma", "napon belül"); teaser titles allowed
("Mutatok valamit", "Mindeközben…", "amiről sokan nem beszélnek").
Every note ends with watch-points + ledger entries, never instructions.

## Type A — FOMC note
**Trigger:** FOMC decision. **Latency target:** same evening, ≤3h after press conference.
**Length:** 6–13K chars (longest when SEP published).

1. No throat-clearing: decision vs consensus in sentence 1, vote split in sentence 2,
   SEP due or not ("az két ülésenként szokás").
2. `## HÁTTÉR` — statement-language parse with quoted phrase deltas („szilárd ütemű" →
   „kissé emelkedett"). If SEP: numbered row-walk GDP → unemployment → PCE → funds-rate
   median, each with delta vs previous SEP + one-line read + a combination verdict.
   Dot-plot arithmetic spelled out ("a 3,4%-os medián ≈ egy 25 bp-os további vágás").
3. `## SAJTÓTÁJÉKOZTATÓ` — thematic Q&A blocks; track **non-answers** explicitly
   ("két dolgot látványosan nem vitt tovább").
4. `## HATÁSOK` — same-day DXY, yields (2y!), metals, S&P, BTC intraday TA,
   CME repricing before→after.
5. `## Összesítés` bullets + `## Személyes kommentár` — one conditional scenario
   ("aduász a pakliban" framing) + follow-up promise ("Holnap külön foglalkozunk…").
   Meta-rule to repeat when relevant: "a következő napok irányai szoktak meghatározóbbak
   lenni, mint az első reakció" + why crypto digests FOMC in days (bond+FX+equity repricing).

## Type B — Macro-data reaction (CPI/PCE/jobs/PMI)
**Trigger:** release. **Latency:** same day. **Length:** 2.5–4.5K chars.

1. Print vs consensus vs prior + revisions in two sentences; paradox hook if present
   ("Annyi lett, amennyit vártak, a hangulat mégis elromlott.").
2. `## A MOTORHÁZTETŐ ALATT` — decomposition: participation, wage mass, revisions,
   energy/base effects; soft vs hard data.
3. Fed-mandate logic chain → CME FedWatch repricing.
4. Cross-asset reaction, then BTC (levels, liquidation map if violent).
5. `## KOMMENTÁR` — was it predictable, what reverses it, data promise for follow-up.

## Type C — Geopolitical note
**Trigger:** escalation/de-escalation headlines (incl. weekends — 24/7 proxies like
Hyperliquid oil perp when markets closed). **Length:** 2.5–7K chars.

1. The development (paraphrased primary source, quoted + translated).
2. The turn: "Van azonban a háttérben néhány érdekesség" — enumerated hidden angles
   (chokepoint stats, deployments per named agencies, budget line items).
3. Contrarian mechanics section (e.g. auction calendar vs rhetoric) — clearly labeled
   speculation ("egymás között beszélhetünk…").
4. Crypto relative-strength check: BTC vs gold vs indexes, TOTAL3.
5. **Anti-panic machinery (mandatory in scary events):**
   - size-contextualization (absolute $ put next to a graspable comparison, HUF conversion),
   - historical base rates with source (avg drawdown, recovery windows, N of conflicts),
   - both-sides risk accounting ("Megtörténhetne? Persze. Hogyan lehet felkészülni?
     Leginkább alacsonyabb kitettséggel."),
   - ritual humility close ("a jövőt senki sem láthatja előre").
6. `## SZEMÉLYES KOMMENTÁR` — questions and watch-points, not predictions.

## Type D — Thematic explainer / sector deep-dive
**Trigger:** narrative saturation ("a csapból is X folyik") or a conference/report.
No same-day pressure. **Length:** 2.5–10K chars.

1. Zeitgeist hook (everyone/nobody is talking about X).
2. `## HÁTTÉR` — patient definitions in `Megj.:` asides.
3. Data core quoting **named** outside specialists (bank research, surveys with N + AUM +
   field dates + staleness caveat).
4. `## HOGYAN KAPCSOLÓDIK IDE A KRIPTOSZEKTOR?` — explicit bridge (capital rotation,
   correlation, flows).
5. `## TECHNIKAI KÉP` — with "TA alone is insufficient" caveat.
6. `## PREDIKCIÓK` — analyst forecast table (relayed, flagged as relayed in ledger) +
   humility close ("Jósgömbje senkinek sincsen.").

## Type E — Institutional-positioning update
Monthly-ish (fund manager surveys, 13F season). Methodology + staleness caveats FIRST
(survey window, N, AUM, filing lag). Numbered walk of ~10 items, extremes read as
contrarian signals. 3-bullet distillation + copy-trading warning.

## Shared rules
- Named sources always (improvement over benchmark's "a hírek szerint").
- Every quantitative claim tagged `[src:...]`.
- Watch-points with named tripwires (levels, dates) → ledger.
- Cross-reference the content ecosystem: back to "a vasárnapi anyag", forward promises
  logged and kept (a broken promise is a rubric deduction).
